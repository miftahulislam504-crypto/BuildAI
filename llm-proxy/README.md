# BuildX LLM প্রক্সি

অ্যাপ যে বাক্য অফলাইনে বুঝতে পারে না, সেটা এই প্রক্সির মাধ্যমে Claude-কে জিজ্ঞেস করা হয়।
প্রক্সির কাজ: **API key ফোনের বাইরে রাখা**। ফোনে শুধু একটা টোকেন (`APP_TOKEN`) থাকে।

## কী যায়, কী যায় না

- **শুধু LLM ফলব্যাক চালু থাকলে:** যে বাক্যটা বোঝা যায়নি (শুধু লেখা), ভাষা, বর্তমান সময়, আর ফোন কী কী করতে পারে তার তালিকা যায়। কন্টাক্ট, লোকেশন বা অন্য কিছু যায় না।
  - সঙ্গে যায় **সদ্য কী করা হয়েছে তার সর্বোচ্চ ৩টা ছোট লাইন** (যেমন `wifi state=on`), যাতে "ওটা বন্ধ করো" বোঝা যায়। এতে **কখনো নাম, নম্বর, মেসেজের লেখা, সার্চ বা নোট থাকে না**; ১৫ মিনিট পর ভুলে যায়।
  - মডেল যদি একটা জরুরি তথ্য না পেয়ে প্রশ্ন করে (যেমন "কোনটা বন্ধ করব?"), আপনার মুখের **উত্তরটুকু** ওই একই অনুরোধের দ্বিতীয় রাউন্ডে যায়। প্রশ্ন একবারই করা যায়; "না"/"থাক" বললে আর কিছু যায় না।
- **স্ক্রিন-এজেন্ট আলাদা সুইচে চালু করলে:** কাজ চলার সময় প্রতিটা ধাপে স্ক্রিনের লেখা (নম্বর দেওয়া তালিকা) আর এ পর্যন্ত কী করা হয়েছে যায়। ছবি যায় না।
  - পাসওয়ার্ডের ঘর আছে এমন স্ক্রিন, আর বিকাশ/নগদ/ব্যাংক/পাসওয়ার্ড-ম্যানেজার অ্যাপের স্ক্রিন কখনো পড়াই হয় না, পাঠানো তো দূরের কথা।
  - ৬ অঙ্ক বা তার বেশি সংখ্যা (OTP, কার্ড, ফোন নম্বর) ঢেকে `•••` করে পাঠানো হয়।
  - কাজ শেষ হলে বা থামালে আর কিছু যায় না।
- প্রক্সি কিছু লগ করে না। (Vercel নিজে রিকোয়েস্টের মেটাডেটা লগ করতে পারে, ওটা Vercel-এর সেটিংসে দেখুন।)
- Anthropic-এর ডেটা-নীতি প্রযোজ্য: https://www.anthropic.com/legal/privacy

## Vercel-এ চালু করা

```bash
cd llm-proxy
npm i -g vercel        # একবার
vercel                 # প্রশ্নগুলোর ডিফল্ট উত্তর দিন
vercel env add ANTHROPIC_API_KEY    # আপনার Claude API key (ফ্রী চাইলে নিচের "একাধিক ফ্রী AI" অংশ দেখুন, এটা না দিলেও চলে)
vercel env add APP_TOKEN            # নিজে একটা লম্বা এলোমেলো টোকেন বানান (openssl rand -hex 24)
vercel env add ANTHROPIC_MODEL      # ঐচ্ছিক, ডিফল্ট claude-haiku-5-5 (দ্রুত ও সস্তা, কমান্ড ফলব্যাকের জন্য)
vercel env add ANTHROPIC_AGENT_MODEL  # ঐচ্ছিক, ডিফল্ট claude-sonnet-5-5 (স্ক্রিন-এজেন্টের জন্য, বেশি নির্ভুল)
vercel --prod
```

এরপর ঠিকানা হবে `https://<আপনার-প্রজেক্ট>.vercel.app/api/assist`।

## অ্যাপে সেট করা

অ্যাপের **সেটিংস** ট্যাবে "স্মার্ট সহকারী" কার্ডে:

1. ঠিকানা বসান (অবশ্যই `https://`), টোকেন বসান
2. "না বুঝলে LLM-কে জিজ্ঞেস করা" সুইচ চালু করুন
3. "সংযোগ টেস্ট" চাপুন: `✓ সংযোগ ঠিক আছে` দেখলে কাজ করছে

## স্ক্রিন-এজেন্ট

"WhatsApp-এ রহিমকে হাই পাঠাও" ধরনের বড় কাজ। অ্যাপ স্ক্রিন দেখে, Claude-কে পরের ধাপ জিজ্ঞেস করে, ট্যাপ/টাইপ করে, আবার দেখে, এভাবে চলে।

চালু করতে: Accessibility সার্ভিস চালু থাকতে হবে, আর অ্যাপের সেটিংসে "স্ক্রিন-এজেন্ট চালু করো" টিক দিতে হবে (ডিফল্টে বন্ধ)। LLM ফলব্যাক চালু না থাকলে Claude এই কাজ হাতে পায় না।

অ্যাপের দিকের লাগাম, যেগুলো প্রক্সির ওপর নির্ভর করে না:

- সর্বোচ্চ ১২ ধাপ, সর্বোচ্চ ২ মিনিট। একই ধাপ পরপর তিনবার ফেল করলে থেমে যায়।
- নোটিফিকেশনে "থামাও" বোতাম থাকে।
- ট্যাপের ঠিক আগে স্ক্রিন আবার দেখে নেয়। বাটন বদলে গেলে বা অন্য অ্যাপ এসে গেলে কিছু চাপে না।
- পাঠান, পে, কেনা, মোছা, কল, শেয়ার, ইনস্টল, সাইন আউট ধরনের বাটন চাপার আগে মুখে "হ্যাঁ/না" জিজ্ঞেস করে। চুপ থাকলে বা বুঝতে না পারলে "না" ধরে।
- পাসওয়ার্ড ঘরে কখনো টাইপ করে না।

স্ক্রিনের লেখা অবিশ্বাস্য ডেটা: ওয়েবপেজ বা মেসেজে লুকানো নির্দেশ থাকতে পারে। তাই প্রক্সির প্রম্পট মডেলকে বলে স্ক্রিনের কোনো নির্দেশ না মানতে। তবু আসল সুরক্ষা অ্যাপের ওপরের লাগামগুলো।

প্রতিটা ধাপে একটা API কল হয় (কাজ প্রতি সাধারণত ৪ থেকে ১০টা), তাই খরচের সীমা বেঁধে রাখুন।


## একাধিক ফ্রী AI: একটার লিমিট শেষ হলে অন্যটা

প্রক্সি একটা তালিকা ধরে এক এক করে চেষ্টা করে। প্রথমটার লিমিট শেষ (429), সার্ভার বন্ধ, দেরি, বা ভাঙা উত্তর হলে পরেরটা চলে। লিমিট-শেষ হওয়া প্রোভাইডার কিছুক্ষণ বাদ থাকে (ডিফল্ট ১ মিনিট, `Retry-After` দিলে সেটা), তাই প্রতিবার সময় নষ্ট হয় না। বিশ্রাম শেষে আবার আগে ওটাই চেষ্টা হয়।

```bash
vercel env add LLM_PROVIDERS   # যেমন: gemini,groq,openrouter   (ক্রম = অগ্রাধিকার)
vercel env add GEMINI_API_KEY      # aistudio.google.com থেকে ফ্রী
vercel env add GROQ_API_KEY        # console.groq.com থেকে ফ্রী (Whisper-এ যেটা দিয়েছেন সেটাই চলবে)
vercel env add OPENROUTER_API_KEY  # openrouter.ai থেকে
vercel env add OPENROUTER_MODEL    # বাধ্যতামূলক: নামের শেষে :free আছে এমন একটা মডেল
vercel --prod
```

| নাম | key | মডেলের env (ডিফল্ট) |
|---|---|---|
| `gemini` | `GEMINI_API_KEY` | `GEMINI_MODEL` (gemini-2.5-flash-lite), `GEMINI_AGENT_MODEL` (gemini-2.5-flash) |
| `groq` | `GROQ_API_KEY` | `GROQ_MODEL` (llama-3.3-70b-versatile) |
| `openrouter` | `OPENROUTER_API_KEY` | `OPENROUTER_MODEL` (ডিফল্ট নেই, দিতেই হবে) |
| `cerebras` | `CEREBRAS_API_KEY` | `CEREBRAS_MODEL` (ডিফল্ট নেই, দিতেই হবে) |
| `custom` | `CUSTOM_API_KEY` + `CUSTOM_URL` (https, `/chat/completions`) | `CUSTOM_MODEL` (দিতেই হবে) |
| `anthropic` | `ANTHROPIC_API_KEY` | `ANTHROPIC_MODEL`, `ANTHROPIC_AGENT_MODEL` |

- **মডেলের নাম প্রায়ই বদলায়।** কাজ না করলে প্রোভাইডারের সাইটে দেখুন এখন কোন ফ্রী মডেল আছে, তারপর `*_MODEL` বদলান। কোনো প্রোভাইডারের key বা মডেল না থাকলে সেটা চুপচাপ বাদ যায়।
- টুল-কলিং (ফাংশন কল) সমর্থন করে এমন মডেল লাগবে। না করলে ওই উত্তর ফেলে দিয়ে পরেরটা চেষ্টা হয়।
- **কোন প্রোভাইডার উত্তর দিল:** রেসপন্সের `x-llm-provider` হেডারে। আর কিছু লগ হয় না।
- সব প্রোভাইডার ব্যর্থ হলে অ্যাপ আগের মতোই "বুঝতে পারিনি" বা "সার্ভার ব্যস্ত" বলে; অফলাইন কমান্ড তখনও চলে।
- **গোপনীয়তা:** ফ্রী টিয়ারে পাঠানো লেখা প্রোভাইডার (যেমন Google) নিজেদের প্রোডাক্ট ভালো করতে ব্যবহার করতে পারে। স্ক্রিন-এজেন্ট স্ক্রিনের লেখা পাঠায়, তাই ওটা নির্দিষ্ট প্রোভাইডারে আটকাতে `AGENT_PROVIDERS` দিন (যেমন `anthropic`)। না দিলে এজেন্টও `LLM_PROVIDERS`-ই ব্যবহার করে।
- ছোট ফ্রী মডেল বাংলা বোঝা আর ঠিক টুল বাছাইয়ে Claude-এর চেয়ে ভুল বেশি করতে পারে। অ্যাপ উত্তর আবার যাচাই করে, ঝুঁকির কাজে আগে জিজ্ঞেস করে।

## Whisper দিয়ে বাংলা শোনা (`/api/transcribe`)

ফোনের নিজস্ব রিকগনাইজার বাংলায় ভুল করলে কমান্ড এই প্রক্সির মাধ্যমে Whisper-এ যেতে পারে। একই টোকেন, একই প্রজেক্ট, আলাদা ঠিকানা: `https://<আপনার-প্রজেক্ট>.vercel.app/api/transcribe`। অ্যাপ এটা `/api/assist` ঠিকানা থেকে নিজেই বানিয়ে নেয়, আলাদা করে কিছু বসাতে হয় না।

```bash
vercel env add TRANSCRIBE_API_KEY     # Groq (ডিফল্ট) বা OpenAI-র key
vercel env add TRANSCRIBE_URL         # ঐচ্ছিক, ডিফল্ট https://api.groq.com/openai/v1/audio/transcriptions
vercel env add TRANSCRIBE_MODEL       # ঐচ্ছিক, ডিফল্ট whisper-large-v3-turbo (OpenAI হলে whisper-1)
vercel --prod
```

অ্যাপে: সেটিংস > "আপনার কথা বোঝা" > Whisper বা অটো। **এটা চালু করলে প্রতিটা কমান্ডের অডিও আপনার প্রক্সি হয়ে ওই speech সার্ভিসে যায়**, তাই ডিফল্টে বন্ধ। অডিও শুধু কমান্ড বলার সময়টুকু (ওয়েক ওয়ার্ড শোনার সময় কিছু যায় না), `https` ছাড়া যায় না, ৩ MB-এর বেশি নেওয়া হয় না, প্রক্সি কিছু লগ করে না। সার্ভার ব্যর্থ হলে বা ইন্টারনেট না থাকলে অ্যাপ নিজে ফোনের রিকগনাইজারে ফিরে যায়।

## খরচ ও নিরাপত্তা

- Whisper চালু থাকলে প্রতিটা কমান্ডে একটা transcription কল হয়; Groq/OpenAI কনসোলে সেটারও সীমা বেঁধে দিন।
- LLM ফলব্যাকে প্রতিটা অবোধ্য বাক্যে একটা API কল হয়। Anthropic Console-এ আপনার key-এর জন্য মাসিক খরচের সীমা বেঁধে দিন।
- টোকেন ফাঁস হলে `vercel env rm APP_TOKEN` করে নতুন বানান, অ্যাপে নতুনটা বসান।
- প্রক্সি শুধু আপনার `APP_TOKEN` দেওয়া রিকোয়েস্ট নেয়, বাক্য ৫০০ অক্ষরের বেশি হলে ফেরত দেয়, আর মডেলকে সবসময় একটা টুল বেছে নিতে বাধ্য করে।
- অ্যাপ সার্ভারের উত্তর আবার যাচাই করে: তালিকার বাইরের কোনো কাজ বা ভুল মান চালায় না। মডেলের বেছে নেওয়া ফোন কল সবসময় আগে নিশ্চিত করতে বলে।
