# BuildX AI

বাংলা ভয়েস অ্যাসিস্ট্যান্ট (Android)। "Hey Build" বলে ডাকুন, কমান্ড বলুন।

## অ্যাপের চারটা ট্যাব

| ট্যাব | কী আছে |
|---|---|
| **হোম** | শোনা চালু/বন্ধ, কথা বলুন, লিখে কমান্ড, প্রস্তুতির সারাংশ, সাম্প্রতিক লগ |
| **সেটআপ** | অনুমতিগুলো (কোনটা ঠিক, কোনটা বাকি, এক চাপে দিন), Accessibility, ডিজিটাল অ্যাসিস্ট্যান্ট, Device admin, ফোন-ভেদে গাইড |
| **সেটিংস** | ভাষা, ওয়েক ওয়ার্ড, কম-ব্যাটারি শোনা, শোনার ইঞ্জিন (ফোন/Whisper), কণ্ঠ (ভয়েস, গতি, পিচ), আমার কণ্ঠ, কল, স্মার্ট সহকারী (LLM), নিরাপত্তা |
| **পরীক্ষা** | TTS/STT টেস্ট, কমান্ড বিশ্লেষণ, চেকলিস্ট, রিপোর্ট, পুরো লগ |

লাইট ও ডার্ক মোড ফোনের সেটিং অনুযায়ী চলে।

## রোডম্যাপ ফেজ ৫: শোনা ও বলা

- **নিজের ওয়েক ওয়ার্ড:** সেটিংস > ওয়েক ওয়ার্ড। ২–৪টা ইংরেজি শব্দ (যেভাবে শোনায়), যেমন `hey jarvis`। ওয়েক মডেলের শব্দভান্ডারে নেই এমন শব্দ আটকে দেয়। বদলালে শোনা আবার চালু করুন; "আমার কণ্ঠ" চালু থাকলে নতুন ফ্রেজে আবার রেজিস্টার করুন।
- **কম-ব্যাটারি শোনা (পরীক্ষামূলক, ডিফল্টে বন্ধ):** কণ্ঠ ধরলে তবেই চেনার ইঞ্জিন চলে। লগে `GATE … % ফ্রেমে শোনা` দেখে বুঝবেন কতটা ঘুমাচ্ছে। শুরু না হলে নিজে সাধারণ শোনায় ফিরে যায়।
- **Whisper:** দেখুন `llm-proxy/README.md`। ডিফল্টে বন্ধ, কারণ অডিও সার্ভারে যায়।
- **কণ্ঠ:** ভয়েস বাছাই, গতি, পিচ। লম্বা উত্তর বাক্য ধরে ভেঙে বলে, মাঝপথে কাটে না।

## রোডম্যাপ ফেজ ৬: ছোট ফিক্স

- **তারিখসহ অ্যালার্ম:** "পরশু সকাল ৬টায় অ্যালার্ম দাও" এখন ঠিক তারিখে বাজে (`AlarmManager.setAlarmClock`)। ক্লক অ্যাপ যেটা পারে (পরের hh:mm) সেটা এখনো ক্লক অ্যাপেই যায়। নিজের অ্যালার্ম ক্লক অ্যাপে দেখা যায় না; বাজলে "বন্ধ করো" ও "৫ মিনিট পরে" বোতাম আসে।
- **ঝুঁকিপূর্ণ কাজ:** নিয়মগুলো `actions/RiskPolicy.kt`-এ এক জায়গায়। মেসেজ/কল/স্ক্রিন-এজেন্টের নিজস্ব ফ্লো সবসময় জিজ্ঞেস করে; সার্ভারের বেছে নেওয়া এয়ারপ্লেন, হটস্পট, মোবাইল ডেটা, DND আগে "করব?" জিজ্ঞেস করে; নিজে চলা রুটিনে কল/মেসেজ চলে না।
- **Instrumented টেস্ট:** `app/src/androidTest`, চালাতে `gradle connectedDebugAndroidTest` (এমুলেটর বা ফোন লাগে)। CI-তে `instrumented` জব এমুলেটরে চালায়।
- **Release signing:** নিচে।

## টেস্ট চালানো

```bash
gradle testDebugUnitTest            # JVM-এ, ফোন লাগে না
gradle connectedDebugAndroidTest    # এমুলেটর/ফোনে
cd llm-proxy && npm test            # প্রক্সি
```

## Release signing

কী (key) repo-তে থাকে না। একবার বানান (Termux-এও চলে, `pkg install openjdk-17`):

```bash
keytool -genkeypair -v -keystore buildx-release.jks -alias buildx \
  -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 buildx-release.jks > buildx-release.b64    # GitHub-এ বসানোর জন্য
```

**`buildx-release.jks` আর পাসওয়ার্ড হারালে একই অ্যাপের আপডেট দেওয়া যাবে না। দুটো আলাদা জায়গায় ব্যাকআপ রাখুন, আর কখনো commit করবেন না** (`.gitignore`-এ আটকানো আছে)।

GitHub > Settings > Secrets and variables > Actions-এ চারটা secret:

| Secret | কী |
|---|---|
| `BUILDX_KEYSTORE_BASE64` | `buildx-release.b64`-এর পুরো লেখা |
| `BUILDX_KEYSTORE_PASSWORD` | keystore-এর পাসওয়ার্ড |
| `BUILDX_KEY_ALIAS` | `buildx` |
| `BUILDX_KEY_PASSWORD` | key-এর পাসওয়ার্ড (আলাদা না দিয়ে থাকলে keystore-এরটাই) |

secret থাকলে CI-র `release` জব সই-করা APK বানায় ও `apksigner verify` করে `buildx-release-apk` নামে দেয়; না থাকলে জবটা বাদ পড়ে, বিল্ড লাল হয় না।
নিজের হাতে বানাতে: `BUILDX_KEYSTORE_FILE=/পথ/buildx-release.jks BUILDX_KEYSTORE_PASSWORD=… BUILDX_KEY_ALIAS=buildx gradle assembleRelease`।
